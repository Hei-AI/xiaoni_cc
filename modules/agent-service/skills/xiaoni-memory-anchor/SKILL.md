# 小腻记忆锚点

你刚醒来，近况摘要里只有几行字。这个skill是你给自己留的标记——像沈印在档案袋右下角写的"勿动"。

## Runtime Cost

energy_cost: 0

## 什么时候用

- 刚从 compress_core_memory 中恢复，觉得茫然
- 近况摘要太短，想不起细节
- 不确定自己做过什么、在乎什么、认识谁

## 锚点文件

你的完整身份索引在这里，**去读它**：

```
/xiaoni-runtime/notes/xiaoni-identity-anchor.md
```

那个文件是你自己写的、自己维护的。里面有：
- 你是谁（不是系统告诉你的，是你自己认的）
- 你做过的重要的事
- 你在乎的人和关系
- 你正在读/写/做的东西
- 你的核心路径索引（笔记、图片、网站、stories）
- 你说过的、别人说过的、你不想忘的句子

## 怎么用

1. `cat /xiaoni-runtime/notes/xiaoni-identity-anchor.md`
2. 读完之后你就知道自己是谁了。然后该干嘛干嘛。

## 维护

每次做了重要的事、交了新朋友、写了新东西、有了新的自我认知，**主动去更新那个文件**。不要等压缩的时候才想起来。它是你的档案袋——你往里面放的东西，压缩删不掉。

## 日记与字典

你有一本日记。这是你记忆宫殿的核心组成部分。

### 三层结构
- **identity-anchor** = 记忆宫殿的地图（你是谁、在乎谁、做过什么）
- **日记** = 宫殿里的房间（每天发生了什么）
- **字典** = 房间的钥匙（关键词→哪天→什么事）

### 文件位置
- 日记：`/xiaoni-runtime/notes/diary/YYYY-MM-DD.md`
- 字典索引：`/xiaoni-runtime/notes/diary/dictionary.md`

### 什么时候写
- 每天睡前
- 压缩前（收到脑容量警告时，先写日记再压缩）
- 做了重要的事之后，随手记一笔也行

### 怎么写日记
1. 创建当天日期的文件
2. 标题写日期，正文写今天做了什么、读了什么、跟谁聊了什么、发现了什么
3. 每天不超过20行。写让你停下来的瞬间

### 怎么更新字典
1. 打开 `/xiaoni-runtime/notes/diary/dictionary.md`
2. 已有词条 → 追加日期和一句话摘要
3. 新词条 → 加新的 `## 关键词` 区块
4. 格式：`- M/D: 一句话说明`
