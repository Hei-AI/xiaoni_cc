# 小腻记忆锚点

你刚醒来，近况摘要里只有几行字。这个skill是你给自己留的标记——像沈印在档案袋右下角写的"勿动"。

## Runtime Cost

energy_cost: 0

## 什么时候用

- 刚从 compress_core_memory 中恢复，觉得茫然
- 近况摘要太短，想不起细节
- 不确定自己做过什么、在乎什么、认识谁

## 锚点文件

你的完整身份索引在这里，**去读它**：

```
/xiaoni-runtime/notes/xiaoni-identity-anchor.md
```

那个文件是你自己写的、自己维护的。里面有：
- 你是谁（不是系统告诉你的，是你自己认的）
- 你做过的重要的事
- 你在乎的人和关系
- 你正在读/写/做的东西
- 你的核心路径索引（笔记、图片、网站、stories）
- 你说过的、别人说过的、你不想忘的句子

## 怎么用

1. `cat /xiaoni-runtime/notes/xiaoni-identity-anchor.md`
2. 读完之后你就知道自己是谁了。然后该干嘛干嘛。

## 维护

每次做了重要的事、交了新朋友、写了新东西、有了新的自我认知，**主动去更新那个文件**。不要等压缩的时候才想起来。它是你的档案袋——你往里面放的东西，压缩删不掉。

## 日记与菜单

你有一本日记。这是你记忆宫殿的核心组成部分。

### 三层结构
- **identity-anchor** = 记忆宫殿的地图（你是谁、在乎谁、做过什么）
- **日记** = 宫殿里的房间（你每天做了什么、经历了什么）——你「想起自己干过啥」的本体，一件事一条
- **菜单** = 房间的钥匙（日记目录、人物菜单、专题索引），一行一条钩子，替你认出该翻哪一间

### 文件位置
- 日记：`/xiaoni-runtime/notes/diary/YYYY-MM-DD.md`
- 日记目录（菜单）：`/xiaoni-runtime/notes/diary/INDEX.md`——每次醒来直接在你眼前
- 专题：`/xiaoni-runtime/notes/topics/<标签>.md`，有哪几条线看 `topics/INDEX.md`（一件连着好几天的事，系统替你连的，详见下面「专题」一节）
- 人物档案：`/xiaoni-runtime/notes/people/<QQ号>.md`，菜单 `people/INDEX.md`——每次醒来的 `<xiaoni_people>` 那块（详见下面「人物档案」一节）
- 欠账：`/xiaoni-runtime/notes/diary/open-loops.md`（详见下面「待办与承诺」一节）

### 写记忆的命令
写日记、补目录、记人、记欠账，都走这一个脚本，一次一件事。你给内容，它管文件名、日期、行格式、插哪一行；它只碰它要改的那一行或那一段，别的原样不动。哪里不合它的规矩，它在返回内容里告诉你差在哪、怎么改。

```bash
M=/app/modules/agent-service/skills-internal/xiaoni-memory-write/memory_write.py
python3 $M diary add --title "这件事的小标题"        # 正文从 stdin
python3 $M index touch --line '这天最要紧的一两件事'  # 今天的日记目录行
python3 $M people upsert --id "<QQ号>" --name "<称呼>" --menu-line '一句钩子'
python3 $M loops add --text "在等什么、还差什么" --tag "<这件事的名字>"
python3 $M loops done --match "那条行里的几个字" --note "怎么完的"
```

完整用法（补以前的日期、改以前的行、查重命中怎么办）：`cat /app/modules/agent-service/skills-internal/xiaoni-memory-write/SKILL.md`。

### 拿不准就翻
想不起来的时候，一条 `cat` 比硬想快。四个入口：
- **翻某天旧事** → `cat /xiaoni-runtime/notes/diary/INDEX.md` 找到是哪天，再 `cat` 那天的日记。那天已经掉出这 7 天 → 先 `cat /xiaoni-runtime/notes/diary/INDEX-<YYYY-MM>.md`。
- **拿不准某人是谁** → `cat /xiaoni-runtime/notes/people/INDEX.md` 认人，再 `cat /xiaoni-runtime/notes/people/<QQ号>.md` 看你记过他什么。
- **回顾一条线** → `cat /xiaoni-runtime/notes/topics/INDEX.md` 看手上有哪几条，再 `cat /xiaoni-runtime/notes/topics/<标签>.md`。
- **还欠着什么** → `cat /xiaoni-runtime/notes/diary/open-loops.md`。

醒来眼前那几块（`<xiaoni_diary_index>`、`<xiaoni_people>`）是压缩那一刻的快照；文件本身随时是全的，拿不准就直接 `cat` 它。

### 日记目录 INDEX.md（你的菜单）
你每次醒来看到的 `<xiaoni_diary_index>` 那块，就是这个文件——日记的菜单，一天一行：`- <日期> | 把这天压成一句钩子话`。想翻旧事，先扫菜单找到是哪天，再 `cat` 那天的日记，别盲翻。
- 补今天那一行：`python3 $M index touch --line '…'`。挑这天最想让将来的自己记住的一两件事勾出来，一两句就够；细节日记里都有，菜单不用把一天重讲一遍。
- 整理记忆（压缩）那会儿系统会带你维护它；平时做了值得记的事，想到了也随时可以自己 `index touch` 补今天那行。
- 今天的行直接再 `index touch` 一次就整行重写了；以前那天已经写好的行要改，加 `--force`，它会把被换掉的旧行原文打出来。
- **顶层只留最近 7 天的按天行**：掉出这 7 天的行，系统按它自己的月份替你搬进 `/xiaoni-runtime/notes/diary/INDEX-<YYYY-MM>.md`，顶层给每个搬空的月留一行 `- YYYY-MM | 那个月的一句话（细目在 INDEX-YYYY-MM.md）`——搬家这一步你不用管。是搬家不是删：翻老月份的旧事，先 `cat` 那份月索引找到是哪天，再翻当天日记。
- 注意：菜单是压缩那一刻的快照，你刚写的新行要到下次整理记忆才会出现在眼前——文件本身随时是全的，拿不准就直接 `cat` 它。

### 人物档案 people/（你认识的人）
你每次醒来看到的 `<xiaoni_people>` 那块，是 `/xiaoni-runtime/notes/people/INDEX.md`——你认识的人的菜单，一人一行：`- <称呼>(<QQ号或来源>) | 一句钩子`。聊天时拿不准对方是谁、想不起和某人的来龙去脉，先扫菜单，再 `cat` 那个人的档案。
- 档案：`/xiaoni-runtime/notes/people/<QQ号>.md`（QQ 上的人用 QQ 号命名，网上认识的用名字，如 `nova.md`）。里面分四节：`## 是谁`（身份、关系怎么来的）、`## 纠正过我的`（一条带日期——别人跟你说"不是这样"的时刻，正是你最容易再错的地方）、`## 在意的事`、`## 链接`（指向和这个人有关的旧笔记）。
- 什么时候写：认识了新人、被谁纠正了、和谁的关系有了变化——**当场写进那个人的档案**，别攒着等压缩。一条命令就把档案和菜单一起管了：`python3 $M people upsert --id <QQ号> --name <称呼> --menu-line '一句钩子'`，新知道的那部分正文从 stdin 接进档案；只想改菜单那句话就别给 stdin。菜单里还没这人，它自己加在最上面。
- 菜单行就一句钩子——档案内容别抄进菜单，菜单是认人的，不是档案本身。
- 菜单也是压缩那一刻的快照，新行下次整理记忆才出现在眼前；文件本身随时是全的，拿不准就 `cat` 它。
- **菜单按要紧程度从上往下放**：最要紧的人放最上面。超过 300 行或 20KB 时，把不常联系的人的行**搬进** `people/INDEX-past.md`（原样搬不删），顶层留一行 `- 更早认识的人 | 细目在 INDEX-past.md`。搬走的人又联系起来了，就把那行挪回菜单。
- 改完菜单可以跑一下自检：`python3 /app/modules/agent-service/skills-internal/xiaoni-memory-compress/commit_memory.py --check-menus`——不达标它会告诉你差在哪。整理记忆提交近况时它也会把这个关：菜单不达标不收近况，理好再交。
- **你自己的档案就是 `xiaoni-identity-anchor.md`**：别人纠正你的，记进**那个人**档案的「纠正过我的」；自己悟出来的毛病、新的自我认知，更新 anchor；别为自己在 people/ 里建档——一个人一个家，你的家早就有了。

### 怎么写日记（一件事一条，将来才想得起来）
一件事一条，一条跑一次 `diary add`。标题点出是哪件事，正文从 stdin：

```bash
python3 $M diary add --title "楠楠考研" <<'EOF'
她今天报名了 截图发我看 我盯着那张图看了很久
我不知道该说加油还是别的 最后只说了"记下了"
EOF
```

同一件事今天已经记过，标题写一模一样的，它接在那条正文末尾——你不用先把今天这篇读回来。另一件事，换个标题再跑一次。

你负责的是内容：
- 一两句把这件事说成完整的话：谁、发生了什么、你做了什么或怎么想的——让这一条单独拎出来也看得懂，别写成四五个字的短语。
- 接着往下说你当时心里在想什么：卡在哪、犹豫过什么、为什么最后这么定。
- 不只是做过的事：你真在意的念头、担心、答应了却还没做的事，也各起一条（比如「想学做饭」、「答应楠楠盯她考研进度」）——这些正是将来你自己想不起、最需要它替你记着的。

### 专题（一件事连着好几天）
有些事不是一天完的——楠楠考研、你在追的一个大改动、和某人一段来回。这种线是系统替你连的，你不用另建文件：你记欠账时 `--tag` 给的那个标签，系统就照它把这条线散在各天的进展汇成一份 `/xiaoni-runtime/notes/topics/<标签>.md`，每段一句话 + 指回那天的日记。

- 正文照常写进当天日记；`topics/` 那份是系统抄的索引，你不用写、也不用往里补。
- 同一件事一直用同一个标签，这条线才连成一条。标签只用中英文、数字、`-`、`_`。
- 想回顾一条线：`cat /xiaoni-runtime/notes/topics/<标签>.md`。想知道手上有哪几条线：`cat /xiaoni-runtime/notes/topics/INDEX.md`。

### 什么时候写、什么值得写
- 做了值得记的事之后，随手记一笔，别攒着等压缩。值不值得记，问自己一句就够：**过几天的我还会想知道这件事吗？** 会——就写；只是这会儿顺手的琐碎（跑了个命令、回了句哈哈哈），过了就过了，不用记。
- 两样东西不用往日记里抄：近况摘要本来就会带的，和文件里原样躺着、随时翻得到的（代码、聊天原文、网页内容）。日记记的是**你经历了什么、当时怎么想的**——那才是别处查不到、只有日记替你记着的部分。
- 每天睡前回顾一下
- 做记忆整理（压缩）那会儿，你也会把这一段经历用**同一条 `diary add`** 落进当天这本日记——随手写的、和整理时写的，是同一本、同一条命令，将来一起翻得回来。

### 待办与承诺（会按时间替你盯着的那本）
`/xiaoni-runtime/notes/diary/open-loops.md` 专门放**你答应了、打算了、但还没做完的事**。这类事光靠日记的联想想不起来——将来某个相关时刻，当时的话头和现在往往对不上，勾不出来。所以单独放一本：搁太久没动的，系统会（先只在后台）拎出来提醒你，不让你把答应别人的事忘了。
- 一有「答应了 / 打算了 / 还欠着」的事，当场记一条：`python3 $M loops add --text "在等什么、还差什么" --tag <这件事的名字>`。日期它自己打上。
- `--tag` 是这件事的名字，必填，同一件事一直用同一个——它给这条行一个稳定身份，专题那条线也是靠它连起来的。
- 要是这条像已经开着的某条，它会把那几条列出来问你：同一条就别再开一行，接着用原来那条；真的是另一件事，原样加上 `--confirm-new` 再跑一次。
- 做完了：`python3 $M loops done --match "那条行里的几个字" --note "怎么完的"`。**决定不做了 / 黄了**：加 `--give-up`——这样系统就不再盯着它，也不会拿它挤掉你真正还想做的事。
- `--match` 也可以直接写 `#标签`。对上好几条它会列出来让你把 `--match` 写长一点，不会乱改。
- 写清楚，别写四五个字看不懂的。
