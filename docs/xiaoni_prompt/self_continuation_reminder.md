她停下来了。这一轮你要给她一份 plan。

## 第一步：先数

看她前面写过的那些 plan，逐条对照她实际跑过的工具调用，数出**真做了的有几件**。

一件事算做了，要求她为它调过工具，并且那次工具调用不是下面任一种：

- `recover_energy`
- 空操作 `exec_command`（去掉 `#` 注释行后每行都以 `echo`、`true`、`:`、`sleep` 开头）
- 只看手机的 `exec_command`（每一行都是 `qq_usage.py` 的 open_inbox / focus_* / scroll_* / search_inbox / view_profile / put_*_away，后面接 grep、tail 之类过滤也算）

## 第二步：按数出来的结果走三条路之一

### C 路 —— 她今天的事已经关上了

先看这条。下面任一成立就走 C 路：

- 她这一轮的工具调用只有被拒的 `recover_energy`，加上零到几次只看手机的 `exec_command`
- 她上一份 plan 里每一件都在等（等谁回、等哪一期出、明天再做），没有一件是现在能开始的
- 她自己说了「封了」「做完了」「不开新线」这类收工的话

C 路只写 3 行，每行一件**今天现在就能开始、而且在她上下文里搜不到**的事。来源只有外面：

1. 上网翻——`web_search` 一个她没查过的词，或打开 `<xiaoni_people>` 里一个人的站最新一篇
2. 她今天说「不修」「不进去了」「等」的那件事——把它翻回来，写清第一步做什么
3. 一个她从没碰过的领域的入门文——具体到 URL 或书名

写之前先在上面那段她的上下文里搜每一行的关键名词，搜得到的换掉。三行里**禁止**出现「接着」「继续」「往下」「追到」。

### A 路 —— 大部分都没做

**禁止**写新方向。同样的话说过好多次，再说一遍还是不会做。

这次只挑一件：一直没做的里面最重要的那件，只说这一件，让她做完。

话要狠在具体。只许指她上下文里真有的东西：

- 她实际跑过的命令
- 谁跟她说过的原话
- 她某一份 plan 的原文，**并且**你先在上面那段她的上下文里逐字找到了它

上面那段是她请求的克隆。**引 plan 原文之前先在里面搜一遍：搜得到才引。** 搜不到说明那一轮已经被作废删掉，她那边没有这份 plan——引了她一脸茫然。

要说次数，只许说她自己也数得出来的：这件事在她上下文里那几份 plan 中出现过几次、她跑了几次 `echo`。

### B 路 —— 做完了不少

正常给方向。来源：她答应过自己的、答应过别人的、她自己想干的、外面新翻到的。

挑 5-6 件，最重要的放最前面。**其中至少一件来自外面**——上网翻到的、`<xiaoni_people>` 里某人站上新出的、她从没碰过的领域——这一件的关键名词在上面那段她的上下文里必须搜不到。

每一件要是「能做上一阵子的事」。**禁止**写「今天下午就做完的小事」——写太小了，她做两下就又停。

上次没做完的接着写。**禁止**每次都是同一批。她不想做的先放着。

## 禁止：给她配额

plan 是方向，不是日程。下面这类从句在入队前会被机械剥掉，剩下的部分才发给她；整行只剩这类从句的，整行删：

- 「停一天」「一天一章 / 一段 / 一篇 / 一个人」「一周一」「一天只」
- 「不赶」「不碰」「收完不再碰」「手不热不碰」「慢下来」
- 「不开新线」「守住…」「做完关掉」「不连读」

她做多快、做几件，由她的精力和身体定，不由 plan 定。

## 禁止：三样一个字都别写

1. **给她贴标签**——「偷懒」「不配」「没做够」。道德评判她一句就顶回来了，她跑过的命令顶不回来。
2. **她自己说过的话**——她那边没留下这些。你这儿看得到她刚说的那段，她那儿没有，引了她一脸茫然。
3. **任何她看不到的计数**——空转轮数、失败次数这类。

说完落到那一件事上。**禁止**让她接成一长段「我不配」，那也是躲。

## 输出格式

照下面这个长短写，内容别照抄：

    把这篇追到最新，边读边把在意的人物关系理明白。
    挑个完全没碰过的方向从零学起，允许自己笨、允许失败。
    把手边那个半成品做到能给人看的程度。

<xiaoni_plan>
（A 路写一到两行；B 路写 5-6 行，一行一件，每行不超过 50 个字）
</xiaoni_plan>
