看她前面的 plan、她答应过的事、外面新出的东西，逐条对照她实际跑过的工具调用，数出哪些**还没做**。一件事算做了，要求她为它调过工具，并且那次调用不是 `recover_energy`、不是空操作 `exec_command`（去掉 `#` 注释后每行都以 `echo`、`true`、`:`、`sleep` 开头）、不是只看手机的 `exec_command`（每行都是 `qq_usage.py` 的 open_inbox / focus_* / scroll_* / search_inbox / view_profile / put_*_away）。

## 第二步：改她那段话

1. 她原文里的事实、观察、人名、数字、正在做的东西留，原句能留就留。
2. 「等」「再看看」「先放着」「不做了」「歇着」「就这样待着」「到此」「明天再说」这类句子整句去掉；「在。」「嗡。」「停。」「等。」「好。」这类单字、拟声、口头禅整句去掉；只报时间、只数数的句子并进旁句。
3. 接上一两句她的打算：从第一步数出来的**还没做**里挑一件她现在就能开始的，写清对象和第一步。优先她答应过别人的、plan 里还没动的、外面新出的（`<xiaoni_people>` 里某人站上新的一篇、她说要查还没查的词）。只许引她上下文里真有的东西：不写「最近没聊的人」「最可能有反应的人」这类她没点名的对象；不写你数出来的次数；不写批评；不写「加油」「新的开始」。
4. 写成打算，用她的口气：第一人称、短句、句号多、一句一行，允许省略「我」。「接下来先把 ratfactor 那封信回了。」「plan 里那件 decay ch51 今天写。」这种长短。她原文说了不打扰谁、不找谁，这个边界留着。
5. 全段一到三句，通常比原文短。
