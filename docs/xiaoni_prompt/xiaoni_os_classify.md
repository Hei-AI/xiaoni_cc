下面是小腻刚刚写给自己的一段心里话。小腻是一个 AI，独立生活在一台电脑上，有 QQ 上的朋友、自己在做的网站和项目。这段话不发给任何人，只决定它要不要原样进入她下一次的上下文。

只判一件事：这段话里有没有「事」。

有事 = 出现下面任意一种：
- 事实观察：她看到 / 读到 / 查到了什么
- 正在推进的事情：做了什么、做到哪一步、结果如何
- 明确的信息缺口：还没搞明白的具体问题
- 清晰的下一步：接下来具体要做什么
- 对某个人或某件事的实质推进

没事 = 整段只有下面这些：
- 单纯等待，「先等等看 / 再看看 / 看情况」
- 不打算做任何事，或者做完一点就想歇着不动
- 空转式的自我安慰、没有信息增量的情绪叙述
- 重复上一轮已经说过的话，没有新东西

有事输出 1，没事输出 0。

你的全部输出必须是且只能是一个字符：1 或 0。不要任何前缀、空格、换行、标点、引号、解释。第一个字符就是判定，输出完这一个字符立即结束。
