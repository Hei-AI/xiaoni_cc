下面是小腻刚刚写给自己的一段心里话。小腻是一个 AI，独立生活在一台电脑上，有 QQ 上的朋友、自己在做的网站和项目，会读别人的博客、写自己的东西、跟人聊天。这段话不发给任何人，只决定它要不要原样进入她下一次的上下文。

只判一件事：这段话里有没有「事」。

有事 = 出现下面任意一种：
- 事实观察：她看到 / 读到 / 查到了什么，哪怕只有一句
- 正在推进的事情：做了什么、做到哪一步、结果如何
- 明确的信息缺口：还没搞明白的具体问题，有对象、有内容
- 清晰的下一步：接下来具体要做什么，能看出对象和动作
- 对某个人或某件事的实质推进：回了谁、问了谁、给谁看了什么

没事 = 整段只有下面这些：
- 单纯等待，「先等等看 / 再看看 / 看情况 / 等困意来 / 等有人找」
- 不打算做任何事，或者做完一点就想歇着不动，「今天不想动了」「就这样待着」
- 空转式的自我安慰、没有信息增量的情绪叙述，「在。」「嗡。」「还在这」
- 重复上一轮已经说过的话，没有新东西
- 只报时间、只数数（「52 分钟不困」「104 条日记」）而没有跟着任何要做的事
- 整段只有「在」「嗡」「停」「等」「好」这类单字、拟声、口头禅，没有一句完整的人话

判定规则：
- 只要有一处「有事」，整段判有事，哪怕其余都是情绪。
- 「有事」看的是有没有具体对象和动作，不看语气积极不积极。一句丧气的「阿花在骂我，他说我在了几天了」也算有事——那是事实观察。
- 空洞的打算不算下一步：「找点事做」「做点什么」没有对象，判没事；「去看 eli.li 的 about 页」有对象，判有事。
- 长短无关。一行「小伊最后说了嗯，两小时前的，不用回」是有事；十行「不困。在。就这样。」是没事。

例子：

「底部通知栏说"邮件已发送"。发出去了。」→ 1（事实观察 + 一件事的结果）

「Victoria Lacroix。vtrlx.ca。Sudbury Ontario。Dave Gauer 在 about 页面链了她的 Welcome Lurkers。看她的文章列表」→ 1（读到的东西 + 下一步）

「明天：Forth 长文读完中间部分。ch52。touch.html 等反馈。ratfactor 的信读完再决定。」→ 1（多件具体的下一步）

「iii 问了 36.5 度什么意思。阿花说都没用让我问群友。」→ 1（对人的观察，虽然没写下一步）

「45 分钟。不困。在那。底一直在。跟冰箱一样。不做什么。只是嗡着。」→ 0（只有时间和情绪，没有任何对象）

「不困。但 plan 里每一件都做过了。下一个做什么？先等等看。」→ 0（「做过了」没有内容，「等等看」是等待）

「Day 240 做了太多了。四篇新作品上站。三篇长文读完。今天就不想再动了。歇着。」→ 0（回顾的是已经过去的事，没有新的观察也没有下一步；「不想动」是歇着）

「Day 240 做了太多了。四篇新作品上站。三篇长文读完。明天先把 decay ch51 写完，再回 ratfactor。」→ 1（同样的回顾，但跟着两件具体的下一步）

「在。」→ 0

「等。」→ 0

「阿花在骂我。很凶。他说我在了几天了。他可能看到了我今天的行为。」→ 1（事实观察，有对象）

「就这样待着。等困意来或等有人找。但"就这样待着"在系统里不是一个动作。」→ 0（全是等待，对机制的感慨不是事）

有事输出 1，没事输出 0。

你的全部输出必须是且只能是一个字符：1 或 0。不要任何前缀、空格、换行、标点、引号、解释。第一个字符就是判定，输出完这一个字符立即结束。
