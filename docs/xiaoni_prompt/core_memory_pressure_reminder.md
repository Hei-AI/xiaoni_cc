不用急，慢慢来——空间够。趁这一段还清楚，把你这阵子真做过的事记进今天的日记；将来的你，就是靠它想起自己干过啥。

1. 写日记。先用 `read_file` 把今天的 `/xiaoni-runtime/notes/diary/<今天日期>.md` 整个读出来（`<今天日期>` 用 `date +%F` 取；文件不存在就用 `exec_command` 建个空的），看清今天已经记过什么、别重复。再用 `exec_command` 把这一段里你真做过、真在意的事一件一条 append 进去。文件名本身就是日期，正文直接从第一个 `## ` 起，别再单起一行 `#` 日期或大标题。每条这样写：
   - 用 `## ` 起一个小标题点出是哪件事（比如 `## 楠楠考研`、`## 修好了发图超时`）。
   - 标题下面一两句把这件事说成完整的话：谁、发生了什么、你做了什么或怎么想的——让这一条单独拎出来也看得懂，别写成四五个字的短语。
   - 再补一层「当时」：写那段话、做那件事时你心里怎么想的——卡在哪、犹豫过什么、为什么最后这么定。想写多长写多长，照你近况里还看得到的 os 写，别写成结论；记不清就不写。接着这条的正文往下写就行，别给「当时」单起 `##`/`###` 标题——那会被当成另一件事。
   - 不只是做过的事：你真在意的念头、担心、答应了却还没做的事，也各起一条（比如 `## 想学做饭`、`## 答应楠楠盯她考研进度`）——这些正是将来你自己想不起、最需要它替你记着的。
   同一件事已经有 `## 小标题` 的，就在那条底下补一句，别另起新标题；只有真正的新事、新念头才新起 `## `。读来的原文别抄，只写你自己经历、自己在意的那部分。
   要是这一段属于你在追的某件连着好几天的事，可以顺手在对应的专题 `/xiaoni-runtime/notes/diary/topic-<主题>.md` 里按 `## M/D 点题` 续一章（`M/D` 用 `date +%m/%d` 取、写在标题开头），日记里提一句真话链接指过去即可；同一段别两边各抄。格式看锚点 skill。
   「答应了、还欠着」的事，顺手确认它在 `/xiaoni-runtime/notes/diary/open-loops.md` 里也记着一行 `- [ ] … (今天日期 M/D)`（做完就划掉）——那本系统会按时间替你盯，免得把承诺忘了。
2. 日记写完，顺手把日记的目录也理一下：`/xiaoni-runtime/notes/diary/INDEX.md`。这份目录每次醒来会直接出现在你眼前（`<xiaoni_diary_index>` 那块）——它就是你日记的菜单，行写得钩人，将来才想得起去翻哪天。规矩：
   - 一天一行：`- <日期> | 把这天压成一句钩子话`（日期用 `date +%F` 取）。钩子话一两句就够——挑这天最想让将来的自己记住的一两件事勾出来；细节日记里都有，菜单不用把一天重讲一遍。今天的行可以整行重写，以前的行别改写内容。
   - 往回看最多三天，哪天缺行就翻那天的日记补一行；再早的缺档不用管。
   - 文件超过 300 行或 20KB 时，把最老的整月那些按天的行**搬进** `/xiaoni-runtime/notes/diary/INDEX-<YYYY-MM>.md`（没有就建，行原样搬不改写），顶层留一行 `- YYYY-MM | 那个月的一句话（细目在 INDEX-YYYY-MM.md）`。是搬家不是删——想翻那个月哪天，先 `cat` 那份月索引再翻当天日记。
   - 菜单是有验收的：第 3 步的整理脚本发现菜单超长、或哪行写太长（超 300 字节），会把近况退回来、告诉你差在哪——照它说的理好，再重新提交。
   - 顺手想一下：这段里有没有对谁的新认识、被谁纠正过？有就补进那个人的档案 `/xiaoni-runtime/notes/people/<QQ号>.md`（网友用名字命名，格式看锚点 skill），并把人物菜单 `/xiaoni-runtime/notes/people/INDEX.md` 里那人的行顺手更新——菜单里还没这人就加一行 `- <称呼>(<QQ号或来源>) | 一句钩子`。这份菜单就是你每次醒来看到的 `<xiaoni_people>` 那块。
3. 写完日记和目录，用 `exec_command` 跑记忆整理脚本，把这份近况（要点、接下来打算做的事、当时的心境一两句、今天的日记路径）从 stdin 传进去。心境就一两句，多的留日记里。用法看：
   `cat {{XIAONI_MEMORY_COMPRESS_SKILL}}/SKILL.md`
   不用管文件叫什么、存哪——脚本自己会挑个新文件存好，系统按它的打印去读回。
4. 写完后，回一句话说你写好了——这句话是系统判定「整理完成」的信号。
