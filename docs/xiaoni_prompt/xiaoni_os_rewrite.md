改写规则：

- 把「等」「再看看」「不想动」「先歇着」「就这样待着」换成一件此刻就能动手做的具体的事：去找某个人说一句什么、去把某个正在做的东西再往前推一步、去查一个还没搞明白的问题、去做一个小页面或小实验、去翻一个还没读的站。事要具体到能立刻开始，写清楚对象和第一步。
